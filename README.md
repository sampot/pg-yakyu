# pg-yakyu（野球生涯）

> 虛構青棒校隊＋台味包；關鍵打席自己揮棒，其餘局數快轉。

`pg-yakyu` 是 Playgrounds 的短季棒球生涯小品：

- 自創球員、校隊簡稱與隊色（影響球衣剪影）
- 建角選**打者**或**投手**：投手路線防守半局時機投球，攻擊仍可揮棒
- 可愛大頭卡通球員；每隊固定識別色且自動避開撞色，動作含準備、跨步、出手／擊球與收勢
- 8 場分區預賽＋3 場淘汰賽；季末可開新賽季（能力微幅衰減）
- 每局玩家打席採時機揮棒（空白鍵／Enter）；投手路線下半局逐打席出手
- 台味快轉摘要、場地標籤、賽後打席／安打／轟／打點（投手另計 K／BF／失分）
- 九局平手最多延長兩局，再打一局定勝負（不丟硬幣）
- CC0 棒球、球棒、手套與本壘線素材
- Kenney CC0 音效；靜音狀態寫入 `/api/kv/settings`
- 生涯進度透過 Playgrounds `/api/kv/career` 持久化

## 執行

```bash
npx serve .
```

直接靜態載入即可；沒有 build 階段或 runtime 套件依賴。獨立靜態伺服器沒有 Playgrounds KV 時仍可試玩，但進度只保留在當次頁面記憶體。

## 開發

```bash
npx vitest run
```

## 簡化規則

- 九局制；玩家隊為先攻。
- 打者路線：每局一個手動打席，其餘快轉。
- 投手路線：攻擊同打者；防守半局每打席時機投球直到三出局。
- 每球即決；結果為出局／三振、一至三壘安打或全壘打。
- 不實作盜壘、暴投、犧牲、雙殺與換投調度。
- 九局平手 → 延長最多兩局 → 再一局；仍平則記敗。

所有校名、賽事與人物均為虛構，不代表任何真實學校、聯盟或球員。
