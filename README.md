# pg-yakyu（野球生涯）

> 虛構青棒校隊＋台味包；關鍵打席自己揮棒，其餘局數快轉。

`pg-yakyu` 是 Playgrounds 的短季棒球生涯小品：

- 自創球員、校隊簡稱與隊色
- 8 場分區預賽＋3 場淘汰賽
- 每局玩家打席採時機揮棒，其餘半局快速模擬
- 虛構校隊、台味應援與紅土全國賽敘事
- 生涯進度透過 Playgrounds `/api/kv/career` 持久化

## 執行

```bash
npx serve .
```

直接靜態載入即可；沒有 build 階段或 runtime 套件依賴。獨立靜態伺服器沒有 Playgrounds KV 時仍可試玩，但進度只保留在當次頁面記憶體。

## 開發

```bash
npx vitest run
```

## 簡化規則

- 九局制；玩家隊為先攻。
- 每局玩家有一個手動打席，其餘打席快速模擬。
- 每球即決；結果為出局、一至三壘安打或全壘打。
- 不實作盜壘、暴投、犧牲、雙殺與換投調度。
- 九局平手時以一分延長決勝。

所有校名、賽事與人物均為虛構，不代表任何真實學校、聯盟或球員。
